# 미사용 배경 시안

`forest-illustration-v1.png`는 초기 비주얼 개선 요청에 따라 내장 이미지 생성 도구로 만든 숲 배경 시안입니다. 사용자가 일러스트보다 선명한 도트 스타일을 원한다고 방향을 변경하여 **게임에는 사용하지 않았습니다**. 원본은 도구가 생성한 원래 디렉터리에도 유지되어 있습니다.

생성 프롬프트는 16:9 숲속 대포 모험 게임의 제목 배경, 이끼 낀 큰 나무, 청록색 숲, 따뜻한 햇빛, 오른쪽 작은 집과 키위새, 텍스트 없는 독자적 픽셀 스타일을 요청했습니다. 결과가 최종 도트 표현 기준과 맞지 않아 배포 자산에서 제외했습니다.

최종 게임의 도트 자산은 `dist/art.js`에서 코드로 직접 그립니다.
