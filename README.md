# I CAN FLY

키위새를 대포로 발사해 숲 끝의 집에 데려다주는 원버튼 도트 액션 퍼즐입니다. 현재 **11개 스테이지**를 플레이할 수 있습니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행한 뒤 https://kuryu6061.github.io/ICANFLY/ 에 접속합니다.

## 조작

- Space / Enter / 게임 화면 클릭 / 발사 버튼: 현재 방향으로 발사
- Tab / Esc: 일시정지 열기·닫기
- M / 맵 보기 버튼: 전체 경로 관전
- R / 처음부터: 현재 스테이지 재시작
- 수집 별, 타이머, 성공 조건은 한 번의 도전을 기준으로 계산

타이머는 첫 발사부터 시작합니다. 일시정지, 지도 관전, 탭 비활성화 중에는 게임과 시간이 함께 멈춥니다. 키보드로 UI 버튼에 초점을 두었다면 Space/Enter는 해당 버튼을 누르는 표준 동작을 유지합니다.

## 대포와 맵 규칙

- 모든 스테이지의 첫 대포는 8방향 대포입니다.
- 이끼색 8방향: 상 → 좌상 → 좌 → 좌하 → 하 → 우하 → 우 → 우상, 0.125초 간격.
- 빨간색 4방향: 상 → 좌 → 하 → 우, 0.25초 간격.
- 두 회전형 모두 한 바퀴에 정확히 1초. 비어 있을 때는 위쪽을 향해 정지하고, 탑승했을 때만 작동합니다.
- 보라색 고정형: 화살표 방향으로 탑승 0.5초 후 자동 발사합니다. 현재 맵에는 이 고정형만 배치합니다.
- 기존 3-2-1 자동형도 엔진에서 지원합니다. 총 1.5초 후 1.5배 속도로 회전 비행합니다.
- 탑승한 캐릭터는 보이지 않습니다. 대포의 몸체, 입구, 화살표는 함께 회전합니다.
- 일반 비행 중에는 캐릭터의 부리가 발사·이동 방향을 향합니다. 8방향 모두 몸 전체의 각도를 맞추며 자동발사형의 회전 비행은 유지합니다.
- 대포 간 비행선은 정확한 45° 또는 90° 단위로 설계합니다. 임의 각도의 보정, 자동 유도, 부드러운 왕복 회전은 없습니다.
- 통로는 실제 비행선과 동일한 좌표로 그립니다. 숲 벽에 부딪히면 빠르게 첫 대포로 돌아갑니다.
- 얼음이 있는 구간에서만 중간에 방향을 바꿀 수 있습니다. 얼음 끝에서 속도를 유지하며 다시 비행합니다.
- 후반 가시문은 정해진 주기로 열리고 닫힙니다. 앞 대포는 수동형이므로 출발 시점을 선택할 수 있습니다.

## 별·기록·저장

1번 스테이지는 60초 / 120초 / 160초 안에 클리어하면 각각 별 하나를 받습니다. 나머지는 120초 / 160초 / 한 번에 수집 별 전부 획득의 세 조건입니다.

여러 판의 조건을 합쳐서 별 3개를 만들 수 없습니다. 한 판에서 달성한 조건 수가 가장 높은 기록을 유지하며, 같은 별 등급에서는 더 빠른 판의 조건을 남깁니다. 최단 클리어 시간은 별 등급과 별개로 저장합니다.

기록, 음량, 캐릭터는 브라우저 `localStorage`의 기존 `kiwi-cannon-save-v2` 키를 유지합니다. 이전 `bestStars/flags` 형식도 읽습니다. 서버·계정 저장은 없으므로 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.

## 코드 구조

- `dist/index.html`: 메뉴, HUD, 일시정지·지도·결과 패널
- `dist/woodland.css`: 데스크톱/작은 화면 대응 UI
- `dist/woodland.js`: 화면 전환, 저장, 카메라, 입력, 오디오
- `dist/core.js`: 렌더링과 분리한 물리·판정·기록 엔진
- `dist/levels.js`: 검증 가능한 11개 맵 데이터
- `dist/art.js`: 코드로 만든 도트 캐릭터·대포·숲·집·효과
- `tests/routes.test.cjs`: 경로와 규칙 회귀 테스트
- `archive/v0.2/`: 사용하지 않는 이전 JS/CSS 보관본
- `UPGRADE.md`: 이번 변경점, 맵별 설명, 다음 개선 제안

## 맵 추가 및 손그림 규칙

검정 동그라미는 8방향, 빨강은 4방향, 보라는 내부 화살표 방향의 0.5초 고정형, 파란 선은 얼음, 별은 수집품으로 해석합니다.

`levels.js`의 맵 좌표는 800px 기준 나침반 격자입니다. 배열의 마지막 점은 집이며, 앞의 점들이 대포입니다. 분수 격자도 사용할 수 있지만 각 비행선의 x/y 변화량은 동일하거나 한쪽이 0이어야 합니다.

`options.ice`는 해당 비행선의 얼음 전환점을, `options.shortcuts`는 출발/도착 대포 인덱스 쌍을, `options.stars`는 경로 인덱스와 경로 위 비율을 지정합니다. `options.gates`는 경로 인덱스, 주기, 닫힘 시간, 위상입니다. 새 맵은 아래 테스트로 반드시 실제 완주까지 확인해야 합니다.

## 검증

```powershell
node tests/routes.test.cjs
```

11개 맵을 120/60/30/15fps 시간 간격으로 시뮬레이션합니다. 각도·통로·다음 대포 포획·전체 별·얼음 전환·지름길·회전 주기·일시정지·카운트다운·기록 비누적성을 검사합니다.

브라우저에서 `/?qa`로 접속하면 하단에 현재 맵 자동 검증 버튼이 나타납니다. 실제 물리 엔진을 이용해 완주하며 QA 판은 기록을 저장하지 않습니다. 일반 주소에는 이 버튼이 없습니다.
